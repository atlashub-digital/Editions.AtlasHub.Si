# AtlasHub Editions — Editorial Model

## Canonical domain

`editions.atlashub.si`

## Canonical publication URL

`/livros/empresa-aumentada`

Dates, themes and edition identifiers are metadata and discovery dimensions, not part of the canonical route.

Historical editions may use:

`/livros/empresa-aumentada/edicoes/2026-10`

## Taxonomy

- Books
- eBooks
- Executive Papers
- Research
- Field Guides
- Essays

## Discovery dimensions

- Theme
- Author
- Year
- Format
- Editorial code

## Editorial codes

Example:

```text
EA–001
Empresa Aumentada
Book
2026.10
```

The code is a catalogue identifier, not a URL.

## Product architecture

AtlasHub Editions publishes knowledge.
AtlasHub Academy turns knowledge into capability.
AtlasHub Solutions and App surfaces turn capability into implementation and operation.

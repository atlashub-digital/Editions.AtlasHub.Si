# Contributing

AtlasHub Editions is proprietary.

## Two-phase workflow

1. Develop and review in `nexflowx-hub/Editions.AtlasHub.Si`.
2. Promote the reviewed release to `atlashub-digital/Editions.AtlasHub.Si`.

Use focused branches and pull requests. Keep editorial content, software and image rights traceable.

## Before promotion

- build passes;
- responsive review completed;
- canonical URLs preserved;
- rights for external images/content verified;
- no secrets included;
- publication metadata reviewed.

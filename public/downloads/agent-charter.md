## 27. O Agent Charter
O **Agent Charter** será um artefacto central da metodologia AtlasHub.


| Componente | Pergunta |
| --- | --- |
| Missão | Que resultado procura? |
| Trigger | Quando entra em ação? |
| Escopo | Onde começa e termina? |
| Contexto | Que informação precisa? |
| Conhecimento | Que fontes oficiais usa? |
| Memória | O que precisa recuperar? |
| Ferramentas | Onde pode agir? |
| Permissões | Até onde pode ir? |
| Política | Como escolhe? |
| KPIs | Como medimos? |
| Escalamento | Quando chama humano? |
| Observabilidade | Como auditamos? |
